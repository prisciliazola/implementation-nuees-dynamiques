# Implémentation des Nuées dynamiques

Ce projet présente une implémentation de l'algorithme des Nuées dynamiques à partir de zéro (from scratch).

## Représentations utilisées

- Point représentatif
- Ensemble de points représentatifs
- Axes / composantes factorielles
- Distribution de probabilités
- Structure représentative

## Technologies utilisées

- Python
- NumPy
- Matplotlib

## Exécution

Le programme principal est contenu dans le fichier `nuees_dynamiques.py`.

Les dépendances nécessaires sont indiquées dans le fichier `requirements.txt`.
